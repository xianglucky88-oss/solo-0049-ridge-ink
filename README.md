# 岭线排图

启动后会显示内置双峰地形。可粘贴或导入高程格网，修改等高距、选幅和测线，更新图幅后下载该次预览对应的 SVG。再加入一份设计格网即可核清整幅挖填量、挑选工区，并导出班组交底图。

## 启动

需要 Node.js 20 或更高版本。

```bash
npm run build
npm start
```

浏览器访问 `http://127.0.0.1:4812`。可用 `PORT` 调整端口。前端由原生 HTML、CSS、JavaScript 构成。项目可离线运行，使用本机浏览器和 Node.js 标准库。

## 工作流

- 格网与三角化。形成有效三角面。
- 等值线提取。同级交点拼成路径。
- 选幅裁线。输出限制在图幅的线。
- 测线剖面。测点按真实里程排列并报告缺测。
- 矢量图导出。可重复产出同样的 SVG。
- 挖填核量。现状与设计两份格网各自按三角面叠加，在选幅内比对同一位置高程，沿实际零高差线分出挖方、填方，另标无需施工与无法核量。
- 工区划分。同类分片只沿有真实挖深或填深的共边合并；只碰顶点或只沿零深度边相接时各自成区。清单列出片号、面积和方量。
- 选片交底。点图内工区或清单片号勾选/取消，图面与清单同步，实时给出所选挖方、填方合计。交底 SVG 沿用核量图图框与片号，只标所选工区。
- 重新选片。改动格网或选幅并生成新图后，旧的选片归属自动失效，需要重新挑选。

完整核量图随时可以下载；只提供一份格网时照常出等高线和测线剖面。

可参阅 `PROJECT_SPEC.md` 了解输入、规则和接口。构建命令检查语法与服务装载。自动化测试套件留待后续。
