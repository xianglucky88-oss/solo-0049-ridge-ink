# 岭线排图

启动后会显示内置双峰地形。可粘贴或导入高程格网，修改等高距、选幅和测线，更新图幅后下载该次预览对应的 SVG。

## 启动

需要 Node.js 20 或更高版本。

```bash
npm run build
npm start
```

浏览器访问 `http://127.0.0.1:4812`。可用 `PORT` 调整端口。前端由原生 HTML、CSS、JavaScript 构成。项目可离线运行，使用本机浏览器和 Node.js 标准库。

## 工作流

- 格网与三角化。形成有效三角面。
- 等值线提取。同级交点拼成路径。
- 选幅裁线。输出限制在图幅的线。
- 多幅拼版。用同一份设置生成相邻、大小不一的矩形图幅，可切换预览、下载整组 SVG 或逐张补导；共边线端坐标一致，沿共边线段按“竖归西、横归南”处理。
- 测线剖面。测点按真实里程排列并报告缺测。
- 矢量图导出。可重复产出同样的 SVG。

界面里的切换与下载都只使用“更新图幅”最后一次成功返回的整组；若新设置里有图幅无效或过密，状态栏会点名受影响图幅，上一次确认的整组仍可继续预览和补导。接口与分幅 JSON 写法见 `PROJECT_SPEC.md`。

## 测试

```bash
npm test
```

使用 Node 内置测试运行器，覆盖共边线端一致、角尖轻蹭、共边归属、重叠/超限报错与 HTTP 出入口。

可参阅 `PROJECT_SPEC.md` 了解输入、规则和接口。构建命令检查语法与服务装载。自动化测试套件留待后续。
