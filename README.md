# 岭线排图

启动后会显示内置双峰地形。可粘贴或导入高程格网，修改等高距、选幅和测线，更新图幅后下载该次预览对应的 SVG。每个完整独立的等高线闭环会在可放下字框的位置自动标注高程，标注可在图面上拖动调整。

## 启动

需要 Node.js 20 或更高版本。

```bash
npm run build
npm start
```

浏览器访问 `http://127.0.0.1:4812`。可用 `PORT` 调整端口。前端由原生 HTML、CSS、JavaScript 构成。项目可离线运行，使用本机浏览器和 Node.js 标准库。

## 高程标注

- 只有首尾相接、不经过分岔点且未被图框切开的独立闭环参与标注；同一地形、图幅和分级的自动位置固定。
- 字框连同四向留白必须在图框内，并避开缺测区、相邻等高线和其他标注；留白只断开带标注的那一圈墨线。
- 拖动标注时它始终属于抓住的那一圈。落点在图面内、且该圈最近位置放得下字框时确认；否则提示原因，预览和下载都保留上次确认的位置。
- 制图接口与导出接口共用同一套摆放规则，下载的 SVG 与确认过的图面一致。

## 工作流

- 格网与三角化。形成有效三角面。
- 等值线提取。同级交点拼成路径。
- 选幅裁线。输出限制在图幅的线。
- 测线剖面。测点按真实里程排列并报告缺测。
- 矢量图导出。可重复产出同样的 SVG。

可参阅 `PROJECT_SPEC.md` 了解输入、规则和接口。构建命令检查语法与服务装载。自动化测试套件留待后续。
