# 岭线排图

启动后会显示内置双峰地形。可粘贴或导入高程格网，修改等高距、选幅和测线，更新图幅后下载该次预览对应的 SVG。

## 启动

需要 Node.js 20 或更高版本。

```bash
npm run build
npm start
```

浏览器访问 `http://127.0.0.1:4812`。可用 `PORT` 调整端口。前端由原生 HTML、CSS、JavaScript 构成。项目可离线运行，使用本机浏览器和 Node.js 标准库。

## 工作流

- 格网与三角化。形成有效三角面。
- 等值线提取。同级交点拼成路径。
- 选幅裁线。输出限制在图幅的线。
- 按预算出图。以基础等高距为准，自动选取 1/2/5/10 倍中不超过 100 级的最密实档位，保留幅内完整线迹并控制在 20 万绘图点内，预览显示实际采用的等高距。
- 测线剖面。测点按真实里程排列并报告缺测。
- 矢量图导出。可重复产出同样的 SVG。

可参阅 `PROJECT_SPEC.md` 了解输入、规则和接口。构建命令检查语法与服务装载。自动化测试套件留待后续。
