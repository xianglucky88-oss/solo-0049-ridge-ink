# 岭线排图

启动后会显示内置双峰地形。可粘贴或导入高程格网，修改等高距、选幅和测线，更新图幅后下载该次预览对应的 SVG。

## 启动

需要 Node.js 20 或更高版本。

```bash
npm run build
npm start
```

浏览器访问 `http://127.0.0.1:4812`。可用 `PORT` 调整端口。前端由原生 HTML、CSS、JavaScript 构成。项目可离线运行，使用本机浏览器和 Node.js 标准库。

## 工作流

- 格网与三角化。形成有效三角面。
- 等值线提取。同级交点拼成路径。
- 选幅裁线。输出限制在图幅的线。
- 测线剖面。测点按真实里程排列并报告缺测。
- 积水连通。给定水位后在图幅低洼处点选入水位置，标出该水位可达的整片低地；山脊、缺测区、顶角接触和水位平齐的窄坎都不会接通。
- 矢量图导出。可重复产出同样的 SVG。

在侧栏填写水位后，直接在图幅上点选入水位置即可；点击留白、缺测区或不低于水位的位置会提示重新选点。入水位置按地面坐标保留，调整选幅后不会移动，范围始终按全格网计算，图幅只决定看到的部分。也可以直接调用 `POST /api/ridge-ink/sheet` 或 `/export`，在 `water` 中指定 `level`、`x`、`y` 取得同样的范围。

可参阅 `PROJECT_SPEC.md` 了解输入、规则和接口。构建命令检查语法与服务装载。自动化测试套件留待后续。
